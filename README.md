# 心靈澄時 Mindful-Clock V1.0
慢一點，也沒關係。時間不必追趕，生命值得細細品味。

設計一個有溫度的時鐘。

顯示時間的同時，也希望每次打開網頁時，都能得到一點平靜、鼓勵與力量。

採用「溫暖、簡約、療癒、帶一點質感」的設計方向。

# 設計構想

## 1. 精緻指針時鐘
- 立體感時鐘外框
- 時、分、秒針
- 12 個時刻刻度
- 柔和的金色與奶油白配色

## 2. 數位時間與日期
- 即時數位時間
- 星期與完整日期

## 3. 心靈療癒區
- 每日一句溫暖提醒
- 鼓勵、感恩、平安等文字
- 點擊按鈕更換心靈語錄

## 4. 專注時間管理
- 25 分鐘專注計時
- 開始、暫停、重新開始
- 完成時給予鼓勵
